# SchoolConnect - Frontend Client

This is the standalone Frontend user interface for **SchoolConnect**.

## Running Frontend Standalone

You can run or view this frontend in **any** of the following ways:

### Method 1: Direct in Browser (Zero Setup)
Simply double click on [login.html](login.html) or [index.html](index.html) to open in your browser!

### Method 2: VS Code Live Server
1. Open this folder in VS Code.
2. Right click on `login.html` and click **"Open with Live Server"** (usually runs on `http://127.0.0.1:5500`).
3. The frontend will automatically connect to the backend running at `http://localhost:5000`.

### Method 3: Via npm serve
```bash
cd frontend
npm start
```
Frontend will be served on `http://localhost:3000`.

> **Note:** Ensure your backend server is running on `http://localhost:5000` (`cd backend && npm start`).
