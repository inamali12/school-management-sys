# SchoolConnect - Backend REST API Service

This is the standalone Backend API server for **SchoolConnect**.

## Running Standalone

1. Navigate to this directory:
   ```bash
   cd backend
   ```

2. Install dependencies (if not already installed in root):
   ```bash
   npm install
   ```

3. Seed the database:
   ```bash
   npm run seed
   ```

4. Start the backend server:
   ```bash
   npm start
   ```

Server will run on **http://localhost:5000** with RESTful endpoints at `/api/*`.
